# 🎮 ADS EXPERIENCE — MISSÃO: SALVE O SISTEMA

> 🤖 **Transparência sobre o desenvolvimento:** este projeto foi criado com o uso de inteligência artificial, sob supervisão, revisão e aprovação humana do Prof. João Victor Pinheiro da Silva.

Escape Room digital educativo desenvolvido para a **Mostra de Profissões do curso de Análise e Desenvolvimento de Sistemas (ADS)**.

Uma experiência com enigmas, desafios de lógica e uma missão: recuperar os sistemas da empresa **Nexus Tecnologia**.

## 🛰️ A história

Os sistemas da Nexus Tecnologia foram comprometidos. A comunicação apresenta falhas, mensagens suspeitas circulam pela empresa e informações essenciais estão criptografadas.

Sua equipe foi convocada para recuperar cinco módulos. Cada missão concluída revela um fragmento do código necessário para restaurar o sistema.

**Vocês conseguem salvar a empresa antes que o tempo termine?**

## 🎯 Objetivo

Apresentar as áreas de atuação de ADS de maneira divertida e acessível, estimulando:

- Raciocínio lógico.
- Resolução de problemas.
- Trabalho em equipe.
- Atenção aos riscos digitais.
- Interesse por tecnologia e desenvolvimento de sistemas.

**Não é necessário saber programar para participar.**

## 👥 Público e duração

| Item | Descrição |
|---|---|
| Público principal | Estudantes do 3º ano do Ensino Médio |
| Organização sugerida | Equipes de 2 a 3 participantes |
| Duração aproximada | 10 minutos por partida |
| Ambiente principal | Laboratório de informática |
| Controles | Mouse e teclado |

## 🧩 As missões

| Missão | Desafio | Área profissional |
|---|---|---|
| 🛡️ Segurança da Informação | Investigar mensagens e identificar sinais de phishing | Análise de Segurança |
| 💻 Programação | Organizar uma sequência lógica de instruções | Desenvolvimento de Software |
| 🌐 Redes | Restabelecer a comunicação entre dispositivos | Infraestrutura e Redes |
| 🤖 Inteligência Artificial | Investigar um problema nos dados de treinamento | IA e Dados |
| 🔐 Criptografia | Decifrar uma mensagem secreta | Desenvolvimento com foco em Segurança |

Ao completar as cinco missões, a equipe reúne os fragmentos e tenta restaurar o sistema no desafio final.

## 🕹️ Como jogar

1. Abra o jogo no navegador.
2. Informe um nome fictício para sua equipe, se desejar.
3. Leia as orientações e inicie a missão.
4. Resolva os desafios na sequência.
5. Utilize as pistas quando necessário.
6. Reúna os cinco fragmentos do código.
7. Insira o código de recuperação na missão final.
8. Confira o resultado da equipe.

Ao finalizar, utilize **Nova equipe** para preparar a próxima partida.

## 🚀 Executar no computador

O projeto utiliza **HTML, CSS e JavaScript**, sem necessidade de instalação.

1. Baixe o repositório em **Code → Download ZIP**.
2. Extraia o arquivo ZIP.
3. Abra o arquivo `index.html` em um navegador atualizado.

Mantenha os arquivos e as pastas do projeto juntos para preservar estilos, scripts e recursos visuais.

### Uso offline

O jogo foi planejado para funcionar sem internet, com os recursos armazenados no próprio projeto.

Antes do evento, teste a versão baixada em um computador do laboratório com a conexão desativada.

## 🏫 Uso na Mostra de Profissões

### Antes da atividade

- Copie a pasta do jogo para os computadores ou abra a versão publicada.
- Teste uma partida completa nas máquinas.
- Confira o tamanho dos textos e o funcionamento dos controles.
- Prepare uma cópia offline como alternativa.
- Deixe a tela inicial pronta para receber os participantes.

### Durante a atividade

- Organize equipes de 2 a 3 estudantes por computador.
- Explique que os desafios apresentam diferentes profissões da área.
- Incentive a discussão entre os integrantes.
- Oriente o uso das pistas quando houver dificuldade.
- Ao terminar, converse brevemente sobre a experiência e o curso de ADS.

### Entre as equipes

Utilize **Nova equipe** e confirme o reinício para apagar os dados da partida anterior.

> Cada computador executa sua própria partida. O projeto não pressupõe um ranking centralizado entre as máquinas.

## 🛠️ Tecnologias

- **HTML5:** estrutura das telas.
- **CSS3:** identidade visual, layout responsivo e animações.
- **JavaScript:** regras, interações, cronômetro e progressão.
- **SVG:** ilustrações e elementos visuais.
- **LocalStorage:** armazenamento local do progresso, quando disponível.

## 📁 Organização do projeto

Arquivos principais:

- `index.html` — estrutura da aplicação.
- `styles.css` — estilos e apresentação visual.
- `script.js` — lógica e funcionamento do jogo.
- `README.md` — documentação.

Recursos adicionais, quando existentes, ficam nas pastas correspondentes do repositório.

## 🎨 Personalização

O projeto pode ser adaptado para outras turmas, eventos e atividades.

- Edite os textos e desafios nos arquivos em que estão definidos.
- Ajuste cores, fontes e espaçamentos em `styles.css`.
- Modifique regras e comportamentos em `script.js`.
- Preserve os caminhos dos recursos ao mover ou renomear arquivos.

Após qualquer alteração, teste o percurso completo até a vitória e o reinício da partida.

## 🌍 Publicação no GitHub Pages

Para esta versão estática:

1. Abra **Settings → Pages** no repositório.
2. Em **Source**, selecione **Deploy from a branch**.
3. Selecione a branch que contém o jogo.
4. Escolha **/ (root)** se o `index.html` estiver na raiz.
5. Clique em **Save**.
6. Após a publicação, copie o endereço exibido pelo GitHub Pages.

O link publicado pode ser compartilhado com os participantes e utilizado para gerar um QR Code.

## 🔒 Privacidade

O jogo não exige cadastro dos participantes. Utilize nomes fictícios para as equipes.

O progresso armazenado localmente pertence ao navegador utilizado. Ele não representa sincronização entre computadores.

## 📚 Observações pedagógicas

- Os desafios são simplificações voltadas a iniciantes.
- A atividade de IA representa uma simulação pedagógica.
- A cifra de César demonstra um conceito histórico e não deve ser usada para proteger informações reais.
- A missão de segurança trabalha a identificação de sinais suspeitos; uma mensagem aparentemente comum não é garantia de segurança.
- Os exemplos de redes utilizam um cenário específico para facilitar a compreensão inicial.
